# jphakodatetrial1

**Throwaway pipeline-validation trial, not a real product.** Covers
just two 10km mesh blocks (624055, 624056) around Mt. Hakodate
(函館山) and Goryokaku (五稜郭), 43 files total, fed from
`smartmaps/japan-geotiff-dem` on Source Cooperative.

Purpose: end-to-end smoke test of the Mapterhorn source + aggregation
pipeline on this machine's (slate) resources, before committing to the
much larger `jphokkaidodem1` (full Hokkaido) run. Safe to delete once
the trial is verified -- it's not meant to be published or maintained.
